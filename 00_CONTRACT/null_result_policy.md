# Null Result Policy

## Commitment

The research team commits to publishing the null result if SPP ≤ 0 with
95% CI including 0. This commitment is binding and cannot be overridden
by any interpretation, rationalization, or "one more run."

## Trigger Conditions

1. Primary: SPP_mean ≤ 0 AND SPP_ci_lower ≤ 0
2. Secondary: Any secondary metric fails to meet its threshold
   (does not block publication, but must be transparently reported)

## Publication Protocol for Null Results

1. Manuscript title: "Null Result in Self-Predictive Coherence in a
   Developmental Artificial System"
2. All data released in the same format as for positive results
3. All code released with identical licensing
4. Supplementary materials include full deviation log
5. Preprint posted to same venue regardless of outcome

## No Cherry-Picking

1. The primary metric (SPP) cannot be redefined post-hoc.
2. The action space cannot be changed to artificially inflate SPC.
3. The environment cannot be modified to make the self-model look better.
4. Additional phases cannot be added to "try again."
5. The number of runs (3) is fixed.

## Violation = Scientific Misconduct

Any attempt to circumvent this policy is grounds for study abandonment.
